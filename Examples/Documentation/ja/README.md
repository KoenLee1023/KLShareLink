# KLShareLink デモアプリ

> <span lang="ja">[English](../en/README.md) · [简体中文](../zh-Hans/README.md) · [繁體中文](../zh-Hant/README.md) · [日本語](../ja/README.md) · [한국어](../ko/README.md)</span>

KLShareLink は、実行時にサードパーティへ依存しない同期型の Swift パッケージです。scheme と host のフィルターを通過した HTTP(S) URL と任意のプロバイダー名を返します。

## Link Inspector

フィルターを通過した明示 URL を最優先 · 文章中の HTTP(S) URL を出現順に検出 · 設定したプロバイダーのドメインに一致する URL を優先

## Policy Playground

設定したプロバイダーのドメインに一致する URL を優先 · `localhost`、`.local`、`::1`、および文書化された直接指定の IPv4 範囲を拒否 · URL が見つからない場合は旧形式の識別文字列からプロバイダー名だけを返せる

どちらのデモにも専用の `Package.swift` とアプリのエントリポイントがあります。リポジトリ直下のパッケージだけに依存し、wondays のコードやリソースは読み込みません。

このパッケージはリンクの選択だけを行います。通信、リダイレクト先の展開、トラッキングパラメータの削除、履歴保存は行いません。`::1` 以外のローカルまたはプライベートな IPv6 リテラルはフィルターで拒否されません。解決後のアドレスと各リダイレクト先はネットワーク層で検証してください。
