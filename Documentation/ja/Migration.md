# KLShareLink 移行

> <span lang="ja">[English](../../README.md) · [简体中文](../zh-Hans/README.md) · [繁體中文](../zh-Hant/README.md) · [日本語](../ja/README.md) · [한국어](../ko/README.md)</span>

最初に、明示 URL、複数の候補、プロバイダー判定、既存の解析器が拒否する接続先、空の入力に対する現在の動作をテストケースに記録します。次に、ドメインと旧形式の識別文字列を設定へ移し、薄いアダプター層で新旧の結果を比較します。想定した差分だけが残っていることを確認し、パッケージテストと組み込み先アプリの回帰テストが通ってから、重複した解析処理を削除します。

## チェックリスト

- [ ] アプリ側で `ShareLinkProvider` の一覧を用意するか、JSON から読み込みます。
- [ ] 明示 URL と共有テキストは結合せず、別々の引数で渡します。
- [ ] URL とサービス名の有無に応じた4通りの結果をそれぞれ処理します。
- [ ] 通信を始める直前に、DNS の解決結果とすべてのリダイレクト先を再確認します。
- [ ] KLShareLink のパッケージテストを実行します。
- [ ] 組み込み先アプリの回帰テストを実行します。
- [ ] API リファレンスと変更履歴を更新します。
