## 概覽

解析器位於不可信的分享輸入與整合端應用程式的導覽或網路處理之間。先驗證明確 URL，再用 Foundation 偵測文字候選，通過 URL scheme 與 host 檢查後比對提供者。沒有 URL 時才檢查舊版標記。策略是資料，副作用由整合端應用程式負責。

## 行為保證

- 通過過濾的明確 URL 優先
- 依文字出現順序偵測 HTTP(S) 候選
- 優先選擇符合設定提供者的候選
- 拒絕 `localhost`、`.local`、`::1` 與文件列出的直接 IPv4 範圍
- 無 URL 時可回報舊版提供者，但不會虛構目標

## 職責邊界

只負責選擇輸入，不發出請求、不展開重新導向、不清除追蹤參數、不保存歷史，也不取代網路層的 SSRF 防護。除 `::1` 外，其他本機或私有 IPv6 直接位址不會被過濾器拒絕。網路層必須驗證解析後的位址與每次重新導向目標。

API 只回傳計算結果，不會修改整合端 App 的狀態。輸入、設定與系統框架行為相同時，結果也會保持一致。
