先以測試案例記錄舊解析器對明確 URL、多個候選、提供者歸屬、遭拒絕目標與空白輸入的行為。接著把網域與舊版標記移入設定，透過薄型轉接層比較新舊結果。確認只留下預期差異，並通過套件測試與整合端應用程式的回歸測試後，再移除重複解析邏輯。

## 檢查清單

- [ ] 在整合端應用程式定義有順序的 `ShareLinkProvider`，或從 JSON 解碼。
- [ ] 分別傳入明確 URL 與分享文字，不要自行串接。
- [ ] 分別處理 URL+提供者、僅 URL、僅提供者、全空四種結果。
- [ ] 真正連線前再次驗證 DNS 結果與每個重新導向。
- [ ] 執行 KLShareLink 套件測試。
- [ ] 執行整合端應用程式的回歸測試。
- [ ] 更新 API 參考與變更記錄。
