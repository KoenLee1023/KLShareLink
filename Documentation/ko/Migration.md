# KLShareLink 마이그레이션

> <span lang="ko">[English](../../README.md) · [简体中文](../zh-Hans/README.md) · [繁體中文](../zh-Hant/README.md) · [日本語](../ja/README.md) · [한국어](../ko/README.md)</span>

먼저 명시 URL, 여러 후보, 제공자 판정, 기존 분석기가 거부하는 목적지, 빈 입력에 대한 현재 동작을 테스트 케이스로 기록합니다. 도메인과 이전 형식의 식별 문자열을 설정으로 옮긴 뒤 얇은 어댑터 계층에서 이전 결과와 새 결과를 비교합니다. 예상한 차이만 남았는지 확인하고 패키지 테스트와 통합 앱의 회귀 테스트가 통과한 후 중복 분석 코드를 삭제합니다.

## 체크리스트

- [ ] 앱에서 `ShareLinkProvider` 목록을 만들거나 JSON에서 읽어 옵니다.
- [ ] 명시 URL과 공유 텍스트를 합치지 말고 별도 인자로 전달합니다.
- [ ] URL과 서비스 이름의 유무에 따라 나오는 네 가지 결과를 각각 처리합니다.
- [ ] 네트워크 요청 직전에 DNS 결과와 모든 리디렉션 목적지를 다시 확인합니다.
- [ ] KLShareLink 패키지 테스트를 실행합니다.
- [ ] 통합 앱의 회귀 테스트를 실행합니다.
- [ ] API 레퍼런스와 변경 기록을 갱신합니다.
