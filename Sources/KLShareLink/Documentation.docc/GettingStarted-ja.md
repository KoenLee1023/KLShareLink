# KLShareLink — はじめに

共有された文章から、解析器のフィルターを通過するリンク候補を選びます。

KLShareLink は、実行時にサードパーティへ依存せず、共有シートから渡される URL や文章を同期的に解析する Swift パッケージです。scheme と host のフィルターを通過した HTTP(S) URL と任意のプロバイダー名を返します。

解析では、フィルターを通過した明示 URL を最優先します。明示 URL がない、または拒否された場合は、設定済みプロバイダーに一致する最初の候補 URL、残りのフィルター済み URL の順に選択します。URL を選べなかった場合に限り、旧形式の識別文字列を確認してプロバイダー名だけを返します。

## 動作保証

- フィルターを通過した明示 URL を最優先
- 文章中の HTTP(S) URL を出現順に検出
- 設定したサービスのドメインに一致する URL を優先
- `localhost`、`.local`、`::1`、および文書化された直接指定の IPv4 範囲を拒否
- URL が見つからない場合も、旧形式の識別文字列からサービス名だけを返せる

## 責務の境界

このパッケージはリンクの選択だけを行います。通信、リダイレクト先の展開、トラッキングパラメータの削除、履歴保存は行いません。`::1` 以外のローカルまたはプライベートな IPv6 リテラルはフィルターで拒否されません。解決後のアドレスと各リダイレクト先はネットワーク層で検証してください。

導入、API、アーキテクチャ、移行の詳細は、リポジトリ内の日本語ドキュメントを参照してください。
