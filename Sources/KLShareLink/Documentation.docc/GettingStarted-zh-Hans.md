# KLShareLink — 快速开始

从实际收到的分享文本中选择符合解析器过滤条件的链接候选。

KLShareLink 是一个不含第三方运行时依赖、同步且确定性的 Swift 包。它处理显式 URL、文本中的多个候选链接、提供方域名与旧版来源标记，并返回通过 scheme 与 host 过滤的 HTTP(S) URL 及可选的提供方名称。

解析时，通过过滤的显式 URL 始终优先。显式 URL 缺失或被拒绝时，先选择第一个匹配已配置提供方的候选 URL，再选择第一个其余过滤候选。只有完全没有选中 URL 时，才检查旧版标记并仅返回提供方名称。

## 行为保证

- 通过过滤的显式 URL 优先
- 按文本出现顺序检测 HTTP(S) 候选
- 优先选择命中配置提供方的候选
- 拒绝 `localhost`、`.local`、`::1` 与文档列出的直接 IPv4 范围
- 无 URL 时可报告旧版提供方，但绝不虚构目标

## 职责边界

只负责选择输入，不发起请求、不展开重定向、不清理跟踪参数、不持久化历史，也不替网络层完成 SSRF 防护。除 `::1` 外，其他本地或私有 IPv6 直接地址不会被过滤器拒绝。网络层必须验证解析后的地址与每次重定向目标。
