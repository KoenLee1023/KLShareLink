# KLShareLink — 시작하기

공유된 글에서 분석기 필터를 통과하는 링크 후보를 선택합니다.

KLShareLink는 서드파티 런타임 의존성 없이 공유 시트에서 전달된 URL과 텍스트를 동기 방식으로 분석하는 Swift 패키지입니다. scheme과 host 필터를 통과한 HTTP(S) URL과 선택적 제공자 이름을 반환합니다.

분석은 필터를 통과한 명시적 URL을 항상 먼저 선택합니다. 명시적 URL이 없거나 거부되면 설정된 제공자와 일치하는 첫 번째 후보 URL을 선택한 뒤 나머지 필터링된 URL을 선택합니다. URL을 선택하지 못한 경우에만 이전 형식의 식별 문자열을 확인해 제공자 이름만 반환합니다.

## 동작 보장

- 필터를 통과한 명시적 URL을 가장 먼저 사용
- 본문의 HTTP(S) URL을 등장 순서대로 검색
- 설정한 서비스 도메인과 일치하는 URL을 우선 선택
- `localhost`, `.local`, `::1`, 문서에 명시된 직접 입력 IPv4 범위 거부
- URL이 없어도 이전 형식의 식별 문자열에서 서비스 이름을 확인 가능

## 책임 경계

이 패키지는 링크 선택만 담당합니다. 네트워크 요청, 리디렉션 추적, 추적 파라미터 제거, 방문 기록 저장은 수행하지 않습니다. `::1` 이외의 로컬 또는 사설 IPv6 리터럴은 필터에서 거부하지 않습니다. 네트워크 계층에서 해석된 주소와 모든 리디렉션 목적지를 검증해야 합니다.

설치, API, 아키텍처, 마이그레이션의 전체 설명은 저장소의 한국어 문서를 참고하세요.
